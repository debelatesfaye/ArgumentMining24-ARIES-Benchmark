# ArgumentMining24-ARIES-Benchmark

This repository provides a framework for **benchmarking argument mining tasks** using state-of-the-art transformer models (e.g., RoBERTa, GPT-2, T5).  
It supports multiple tasks such as:

- **Sequence Classification**  
- **Token Classification (with sequence classification extension)**  
- **Sequence Alignment (via cross-attention)**
